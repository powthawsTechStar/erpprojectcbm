Export any module as a formatted .xlsx file. The exported file can be re-imported into this system or opened in Excel/Google Sheets.

📥 Import Data from Excel

Upload an Excel file to import records. Use the Export buttons above to download the correct column format first, fill in your data, then import. Records are merged (existing data is kept safe).

📋 Column Guide:
Customers: Name*, GSTIN, Phone*, Email, Address, City, State, Pincode
Products: Name*, HSN*, Unit*, Rate*, GST%*
Quotations: CustomerName*, Date* (YYYY-MM-DD), ProductName*, Qty*, Rate*, GST%*, Terms
Work Orders: CustomerName*, Date*, Site*, Address, Description, Status, CompletionDate
Purchase Orders: Supplier*, Date*, ItemName*, Qty*, Rate*, Contact
Delivery Challans: CustomerName*, Date*, ProductName*, Qty*, Vehicle, Driver, Location
Invoices: CustomerName*, Date*, ProductName*, Qty*, Rate*, GST%*, Reference
* = required
